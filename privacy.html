DIGDIGDIG | PRIVACY POLICY

Privacy Policy

Last updated: November 11, 2026

What digdigdig does

digdigdig is a Chrome extension that helps you search for tracks across music platforms. It reads track details on supported pages and adds search links so you can find the same track on another site — without copying and pasting.

Data accessed

digdigdig reads the following information from supported pages to build search links:

  • Track title
  • Artist name(s)
  • Mix / remix name

This data is processed entirely within your browser.

Supported sites

Site Access scope Purpose
Beatport beatport.com Read track info, inject search links
Soundeo soundeo.com Read track info, inject search links
YouTube youtube.com Read Music card info, inject search links

Bandcamp is a search destination only — digdigdig does not access Bandcamp pages.

Data NOT collected

  • digdigdig does not send track data to any server.
  • digdigdig does not collect personal information, browsing history, or analytics.
  • digdigdig does not use cookies or third-party tracking.

What happens when you click a link

When you click a search link, the destination site receives the search query as part of its URL. This is the same as typing the query into that site's search bar manually. digdigdig does not control how the destination site handles that query.

Storage

Your site preferences (which sites are enabled, which search destinations to show) are saved using Chrome's sync storage API. This data syncs across your signed-in Chrome browsers. No other data is stored.

Permissions

Permission Reason
storage Save your site and destination preferences
activeTab Access the current tab to read track info on supported sites
Host access Run content scripts on beatport.com, soundeo.com, youtube.com

Third-party services

digdigdig does not use remote code, external APIs, or third-party services. All functionality runs locally in your browser.
